# How the main program works

Reads the file "grafos.txt" containing multiple graphs. This file **must be in the same folder as the program**. The program reads all graphs and, in the same reading order, prints `SIM` if a valid coloring exists and `NAO` otherwise.

> [!NOTE] Example files are provided for easier testing. To test a file, paste it into the main folder and rename it to "grafos.txt".

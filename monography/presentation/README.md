
## About the Project

[Original Template Used](https://github.com/maumneto/TemplateBeamerUFC)

Repository containing the presentation slides for the Undergraduate Thesis (TCC) at the Federal University of Ceará (UFC).

**Title:** Map Generation for Roguelike Games from Textual Descriptions Using Large Language Models

## How to Compile

To generate the PDF document, a LaTeX compiler (such as `pdflatex` or `xelatex`) and `biber` for references are required:

```bash
pdflatex filename.tex
biber filename
pdflatex filename.tex
pdflatex filename.tex
```
